# Screenshot Lighting Assistant 0.2.0

Skyrim SE/AEのスクリーンショット撮影向けに、対象Actorの周囲へ3灯の撮影ライトと独立した白色フェイスライトを配置するSKSEプラグインです。0.2.0では、プレイヤー用の常用フェイスライトを追加しました。

## 0.2.0の追加機能

- 円形レイアウトを変えず、上部の小さな人型アイコンから専用の「常用フェイスライト」窓を開きます。
- 専用窓の先頭に機能マスターがあります。OFF中は常用ライトを消し、登録済みのキーボード／ゲームパッド入力を無視します。プレイヤーライトのON状態・調整値・登録キーは保持し、再びONにすると復帰します。
- 常用ライトはプレイヤー専用・白色・影なしで、顔の向きへ追従します。強さ、範囲、上下を撮影用フェイスライトとは別に調整できます。
- 任意のキーボードキーをON/OFFホットキーへ登録できます。「変更」を押した後、メニューを閉じずにキーを入力できます。Escで現在の登録を変えずにキャンセル、「解除」で未設定へ戻します。
- ゲームパッドはキーボードとは別にボタンを登録できます。通常プレイ中に約0.6秒長押しすると1回だけON/OFFし、短押しや押しっぱなしによる連続切替はしません。
- 機能ON/OFF、ライトON/OFF、両方のホットキー、調整値はゲームセーブとは別の `persistent-face.sla` に保存し、ゲーム再起動後も保持します。旧ベータの設定も読み込み、常用ライトの配置だけ顔向き基準へ移行します。
- ロードや場所移動中はいったん撤去し、プレイヤー・セル・描画環境を取得できてから自動で戻します。通常の撮影ライト3灯は従来どおり自動再開しません。
- プレイヤー撮影中に撮影用フェイスライトもONの場合は二重照明を避け、撮影用を一時的に優先します。撮影停止後は常用設定へ戻ります。NPC撮影時はNPCの撮影用フェイスライトとプレイヤーの常用ライトを別々に使用できます。
- 照明、保存、ロード／セル移動後の復元、キーボード／ゲームパッド操作、機能マスター、顔向き固定、状態表示を含む全確認項目がゲーム内で合格しました。beta4と同じ機能コードを0.2.0正式版へ昇格しています。

## 必要環境

- Skyrim Special Edition 1.5.97 または Anniversary Edition 1.6.x
- SKSE64
- Address Library for SKSE Plugins
- SKSE Menu Framework 3
- Microsoft Visual C++ 2015–2022 Redistributable（x64）

VRには対応していません。ESP、Papyrusスクリプト、ゲームINIの変更はありません。

## 導入

1. Skyrimを終了します。
2. MO2で `ScreenshotLightingAssistant-0.2.0-MO2.zip` をインストールします。
3. 旧版を無効にし、ScreenshotLightingAssistant.dllが二重にならないようにします。
4. SKSE経由で起動し、Mod Control Panelから `Screenshot Lighting Assistant > Lighting` を開きます。

Source ZIPとSymbols ZIPはMO2へ導入しません。

## 主な機能

- 対象とカメラを基準にした8方向・最大3灯の撮影ライト
- ライトごとの種類、色、強さ、範囲、距離、高さ、微調整、影、ON/OFF
- 選択中ライトの調整値だけを既定へ戻し、種類・色・影方式・点灯状態を保持する「初期値」
- カメラ基準／顔の向き基準を切り替えられる独立フェイスライト
- プレイヤーまたは周囲の読み込み済み人型NPCを撮影対象として選択
- 戻る／進む、起動中だけ保持する栞
- 登録ライト、お気に入り、プリセット、内蔵サンプル
- 日本語／英語UI。設定がない新規環境は英語で開始
- 上部の人型アイコンから開く、ホットキーと自動復元に対応したプレイヤー用常用フェイスライト

撮影ライトはメニューを閉じても維持されます。ロード、ニューゲーム、メインメニュー、セル変更、対象3Dの消失では安全のため停止し、自動再点灯はしません。常用フェイスライトだけは別管理で、安全な状態になってから自動復元します。

## 登録データ

登録ライト・プリセット・言語・一覧設定・常用フェイスライト設定はゲームのセーブデータには保存しません。仮想Data内の次の場所へ保存します。

`SKSE/Plugins/ScreenshotLightingAssistant/`

MO2では通常、実ファイルが次へ出力されます。

`Overwrite/SKSE/Plugins/ScreenshotLightingAssistant/`

画面下の「登録の保存先 (?)」へマウスを載せると、実際に使用しているパスを確認できます。必要に応じてフォルダー全体をバックアップするか、MO2の専用出力MODへ変換してください。

0.1.27以前のMy Games側に登録がある場合、初回だけ新しい保存先へコピーします。旧ファイルは削除しません。

## プリセットと安全性

プリセットは照明設定だけを保存し、NPC、ActorHandle、カメラ座標、ゲームセーブ、全体の開始状態は保存しません。削除操作は可能な限り `Archived` フォルダーへ退避します。

他のフェイスライト・撮影ライトMODと同時に使うと照明が重なるため、比較時は不要なライトを消してください。このMODはActorのAI、ポーズ、スケジュール、向き、NPCレコードを変更しません。

## 0.1.29について

RC1の新規導入・再起動後の保存・旧版移行と、RC2で追加した「初期値」はゲーム内確認済みです。「初期値」は強さ1.00、範囲4.0m、距離2.20m、高さと3軸微調整0.00m、影の補正1へ戻し、配置方向・種類・色・影方式・点灯状態を保持します。「戻る」で取り消せます。確認済みのRC2と同じDLLを正式版として収録しています。
