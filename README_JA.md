# Screenshot Lighting Assistant 0.3.0

Skyrim SE/AEのスクリーンショット撮影向けに、対象Actorの周囲へ3灯の撮影ライトと独立したフェイスライトを配置するSKSEプラグインです。0.3.0は、検証済みalpha54の機能コードを変更せず正式版表記へ昇格したパッケージです。

## 0.3.0正式版

- CommonLibSSE-NGをv8.4.0へ更新し、Address Library形式5とSkyrim 1.7.104のランタイム定義へ対応しました。
- 同一DLLをSkyrim 1.6.1170と1.7.104.0の両環境で実機確認し、alpha54の全12項目へ合格しました。
- 3灯、2種類のフェイスライト、固定色・自由色、撮影エフェクト、画面演出、保存形式、UI配置は検証済みalpha54から変更していません。
- Skyrim 1.7.104ではSKSE 2.3.1とAddress Library All in One v13以降が必要です。SKSE Menu Frameworkも1.7.104対応版を使用してください。
- Community Shadersは検証時点でSkyrim 1.7.104未対応のため同環境では未確認です。Steamのスクリーンショット機能では正常に反映されました。

## 0.3.0-alpha53の試作機能

- 撮影用フェイスライトと常用フェイスライトへ、共通の `白・暖色・青・ろうそく` と自由色を追加しました。固定色は通常3灯と同じ実照射RGBです。
- 選択中の固定色、または固定色以外の自由色へチェックを表示します。白プリセットへ統合したため、独立した `白に戻す` ボタンはありません。
- 両者の色は独立しており、撮影停止後は常用側の色へ戻ります。色変更は強さ・範囲・位置・ON/OFFを変えません。
- 撮影用の色は履歴・栞・フェイスを含む登録セットへ入り、常用側は従来の専用設定へ保存されます。旧プリセットと旧常用設定は白として互換読込します。
- 既存のライト描画方式をそのまま利用し、3灯、撮影エフェクト、画面演出、alpha51で確定した斜め光の範囲には変更を加えていません。

## 主な機能

- 対象とカメラを基準にした8方向・最大3灯の撮影ライト
- ライトごとの種類、色、強さ、範囲、距離、高さ、微調整、影、ON/OFF
- 選択中ライトの調整値だけを既定へ戻し、種類・色・影方式・点灯状態を保持する「初期値」
- カメラ基準／顔の向き基準を切り替えられる独立フェイスライト
- プレイヤーまたは周囲の読み込み済み人型NPCを撮影対象として選択
- 戻る／進む、起動中だけ保持する栞
- 登録ライト、お気に入り、プリセット、内蔵サンプル
- 日本語／英語UI。設定がない新規環境は英語で開始
- 上部の人型アイコンから開く、ホットキーと自動復元に対応したプレイヤー用常用フェイスライト

撮影ライトはメニューを閉じても維持されます。ロード、ニューゲーム、メインメニュー、セル変更、対象3Dの消失では安全のため停止し、自動再点灯はしません。常用フェイスライトだけは別管理で、安全な状態になってから自動復元します。

## 登録データ

登録ライト・プリセット・言語・一覧設定・常用フェイスライト設定はゲームのセーブデータには保存しません。仮想Data内の次の場所へ保存します。

`SKSE/Plugins/ScreenshotLightingAssistant/`

MO2では通常、実ファイルが次へ出力されます。

`Overwrite/SKSE/Plugins/ScreenshotLightingAssistant/`

alpha34以降は、設定変更・登録・旧データ移行がない読み込みだけの起動では、この空フォルダーを作りません。マーカーがない環境で実際に保存すると、MO2が選んだ出力先へ作成されます。

alpha35では `storage-v2.sla` を保存先の所有マーカーとして使います。Overwriteの `SKSE/Plugins/ScreenshotLightingAssistant/` を専用出力MODへ移すときは、このファイルを含むフォルダー一式を移してください。次回起動時にマーカーの実体がある物理フォルダーを安全に解決し、新規の `.slalight`／`.slaset` と `library-view-v3.sla` もそこへ保存します。ご提示の `S:\MO2 AE\mods\test\SKSE\Plugins\ScreenshotLightingAssistant` はこの条件を満たします。

同じ名前の空フォルダーがあるだけでは保存先にしません。複数MODが同じ仮想フォルダーを提供できるため、内容が正しい既存マーカーを明示的な所有者として扱います。マーカーが無ければMO2の通常動作を尊重し、新規ファイルはOverwriteまたはMO2で指定した出力MODへ入ります。

画面下の「登録の保存先 (?)」へマウスを載せると、実際に選ばれた保存パスを確認できます。必要に応じてフォルダー全体をバックアップしてください。

0.1.27以前のMy Games側に登録がある場合、初回だけ新しい保存先へコピーします。旧ファイルは削除しません。

## プリセットと安全性

プリセットは照明設定だけを保存し、NPC、ActorHandle、カメラ座標、ゲームセーブ、全体の開始状態は保存しません。削除操作は可能な限り `Archived` フォルダーへ退避します。
