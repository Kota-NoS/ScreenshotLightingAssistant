# Screenshot Lighting Assistant 0.1.29 — 開発確認記録

0.1.29 RC1の新規導入・再起動保存・旧版移行と、RC2で追加した「初期値 / Reset values」はゲーム内で合格済みです。同じDLLを0.1.29正式版へ収録しています。

## 正式版へ引き継いだRC2確認項目

1. `ScreenshotLightingAssistant-0.1.29-MO2.zip` だけをMO2へ導入し、画面下が0.1.29、初期値ボタンが「3. 基本設定 / Settings」の横に表示されること。
2. 通常ライトの種類・色・配置方向・影方式・点灯状態を変更し、さらに強さ・範囲・距離・高さ・3軸微調整・影の補正を既定以外へ変更すること。
3. 「初期値 / Reset values」で強さ1.00、範囲4.0m、距離2.20m、高さと3軸微調整0.00m、影の補正1へ戻ること。
4. 種類・色・配置方向・影方式・点灯状態は維持され、「戻る」で全調整値が一度に復元、「進む」で再び既定値になること。
5. 既定値または未配置では無効で、日英・狭い画面幅でも見出しや操作と重ならないこと。

以下は0.1.28までの詳細な回帰確認項目です。

## 0.1.25から継続する確認

1. 撮影ライトを開始し、円の中央下のフェイスON/OFFで点灯。隣の設定ボタンに「カメラ基準 / Camera」「顔の向き基準 / Head facing」があること。
2. 普段使っているポーズや視線操作で顔を横へ向け、顔の向き基準へ切替。顔の前方から照らされること。身体だけの向きではなく、頭の横向き・上下・傾きに追従する想定です。カメラだけを回しても顔に対する光源位置が変わらないことを確認します。
3. カメラ基準へ戻すと従来の照らし方へ戻ること。両方式で上下スライダーを確認します。顔の向き基準では「上」も頭に追従するため、頭を傾けると斜め方向へ動きます。
4. 切替だけでフェイスが勝手に点灯せず、通常3灯の設定・番号選択が変わらないこと。頭の向きを取得できない場合はフェイスだけ待機します。カメラ基準では従来の頭とカメラが近すぎる待機も維持します。撮影開始・シーン有効性の共通カメラ条件は両方式に残ります。
5. 切替→戻る／進む、栞の登録→切替→戻すを確認。フェイスを含めたプリセットを新しい名前で登録し、再起動後に適用して方式が戻ること。サンプルとフェイスなし登録では現在の方式を保持すること。
6. プレイヤーで確認後、同じ手順をNPCでも確認。撮影停止・ロード・対象変更で光源が残らないこと。独自スケルトンや頭の軸が異なる構成では顔の向きが合わない可能性があるため、ズレる場合はカメラ基準へ戻してください。
7. 横並びのメイン画面で、お気に入り4件→5件へ変更。「微調整・削除」は左列の円の下に留まり、右の5件目と縦の余白を共有すること。日英両方と幅変更を確認します。極端に狭い幅・大きいフォントでは重なりを避けて折返し／縦配置になります。

### プリセット互換性

旧SCENE 1形式はカメラ基準としてそのまま読み込み、読み込み時には書き換えません。顔の向き基準を含めた新規登録だけSCENE 2形式です。0.1.24以前へ戻すとその登録は読み込めない警告になりますが、ファイルは残ります。フェイスなし登録・カメラ基準登録・登録ライト・library-view-v3.slaは従来形式のままです。更新前にPresets全体をバックアップしてください。

## 継続するプリセット比較・削除操作の確認

1. 「微調整 / Fine position」の隣に「Light N」と線画のゴミ箱が表示されること。番号は選択中の灯です。未配置では無効、ホバーには登録データを消さない説明が出ます。削除→履歴の「戻る」で復元を確認してください。
2. お気に入り5件を表示し、狭い幅でも削除ボタンや微調整と重ならないこと。6件目には入替先選択が出ること。日英を切り替えて確認してください。
3. 撮影ライトを開始→P→「選択後も開く / Keep open」をON。自作・サンプルを続けて選び、即時反映され、一覧が閉じず、一覧による背景暗転がないことを確認してください。カード選択自体は撮影ライトを開始しません。
4. 「管理 / Manage」をONにした間はカードを押しても照明が変わらないこと。名前変更・削除確認・キャンセルも確認してください。通常の一覧は暗転しませんが、確認ダイアログの暗転は別です。
5. 「選択後も開く」をOFFに戻すと、次の適用で従来どおり閉じること。×で閉じても照明は最後の適用状態を保ちます。
6. 被写体を隠さない位置へ窓を移動・リサイズ→閉じる→Pでもう一度開くと同じ位置・サイズに戻り、チェック状態も残ること。これらは起動中だけで、ゲーム再起動後は中央・チェックOFFに戻ります。画面サイズ変更時は画面内へ補正します。
7. 一覧を開いたままメイン側の照明調整ができること。メニューを閉じる／開く、停止・開始、NPCへの適用も確認してください。最後は撮影ライトを停止します。

### 一覧設定の引き継ぎ

5枠に対応する整理情報は `Presets/library-view-v3.sla` へ保存します。v3がなければv2、なければ旧v1を読みます。旧ファイルは書き換えず、既存のお気に入り順・未使用枠を維持します。新形式が破損している場合は旧形式に勝手に戻さず、保存を止めて警告します。0.1.23へ戻すと旧v2時点の整理状態になります。フェイス込みプリセットの互換性は上の説明を参照してください。

## 継続機能の確認（先にプレイヤー、次にNPC）

1. **名前変更**：お気に入り右の「管理」→登録ライトの「名前変更」。プリセットはP→「管理」ON→自作カードの「名前変更」。日本語／英数字の名前、キャンセル、同名拒否を試します。名前を変えても照明・お気に入り位置・プリセット順が変わらず、再起動後も名前が残るか確認してください。サンプルの名前変更は対象外です。
2. **表示切替**：上のENで英語、JPで日本語に戻します。ライト・プリセット名や照明値はそのままです。停止理由・影の補正・フェイス設定・登録画面・微調整窓のホバー、英語での文字の見切れを確認します。再起動後にも言語が残ることを確認してください。日本語入力は従来のMenu Framework入力環境に依存し、IME自体を追加する変更ではありません。
3. **選択順と影**：白／暖色／青／ろうそくの順を確認します。「影の補正」は(?)なしで、ホバーすると説明が出ます。スポット選択中だけ表示する動作・補正値の保持は従来どおりです。
4. **図**：Pから、1灯・3灯・同じ方向に重ねた灯・OFF・黒色のカードを見ます。外周に対する小丸や中央の比率が以前の図に近く、右の名前／情報や下のカメラと重ならないか確認します。
5. **NPC一覧**：NPCの近くで「対象を選ぶ」。プレイヤーから30m以内の読み込み済み人型NPCを最大64人、距離順で表示します。候補名・距離・RefIDで区別し、選ぶと対象名が変わり全灯が消えることを確認します。一覧を閉じて「撮影ライトを開始」してください。
6. **NPC照明**：3灯の位置・高さ・影・色、頭基準のフェイスライトを調整します。ポーズとカメラを変えて、NPCの胸／頭を基準に追従するか確認してください。NPCはこのMODで静止させないため、撮影中に歩く場合は普段の撮影方法でポーズを固定してください。
7. **補助選択**：コンソールでNPCを選びコンソールを閉じる→「コンソールの選択対象」。または通常のゲーム画面でNPCへ照準を合わせ→「クロスヘアの対象」。メニュー中／フリーカメラで取得できない場合は近くの一覧を使います。無効な物体・対象なしでは照明対象を変更しないことを確認してください。
8. **停止と復帰**：NPC→プレイヤー、対象NPCの読み込み解除、セル移動、ロードを試します。対象の切替は設定を保持して消灯し、ロード後は対象がプレイヤーになります。勝手に再点灯したり、別のNPCへ切り替わったりしないことを確認してください。最後に停止し、残光がないか確認します。

## 保存・バックアップ

- 内部の色番号は変更していません。種類・色だけの登録と、3灯＋任意フェイスのプリセットは従来どおり独立しています。顔の向き基準を含む保存だけ新形式です。
- 名前変更は同じ登録ファイルを原子的に置き換えます。その前に `Archived/<日時等>-before-rename-<元のファイル名>` へ元の内容を退避します。名前を戻すだけなら再び名前変更を使えます。バックアップから復元する場合はゲーム終了後、現在のファイルも別に保管し、該当する元のファイル名で置き戻します。退避ファイルをそのまま別名でPresets直下へ置くと別の登録として扱われます。
- 言語だけはPresetsの一つ上の `ui-language.sla` に保存します。これを別に退避すると0.1.28以降の既定である英語へ戻ります。壊れた設定は保持して警告し、勝手に上書きしません。
- 履歴にある過去の登録名は当時の表記です。栞・履歴・NPC選択は起動中の作業用で、対象NPCはプリセットに含まれません。
- ゲームやMO2への自動配置はこの作業では行っていません。

## 導入

Skyrimを完全終了してからMO2で導入用ZIPを導入し、旧Screenshot Lighting Assistantと入れ替えてください。DLLを二重に有効にせず、旧版のZIPは戻せるよう残してください。SKSE64・Address Library・SKSE Menu Framework 3が必要です。ESPはありません。普段のセーブを上書きせず、テスト用セーブで確認してください。ゲーム全体のINI・SAM・他MODは変更しません。

## 0.1.19でまず確認する操作

1. 配置図のライトは実際の設定RGBを表示します。番号は背景色に合わせて黒／白に切り替わり、金色の外枠は編集位置です。OFFは暗い色＋斜線。黒色のONは黒い丸＋白い番号（斜線なし）です。登録名との紐付けは増やしていません。
2. 赤・青などの3灯を同じ方向に重ね、色を混ぜず番号ごとに表示されるか確認してください。縮小図では重なった丸だけ少し大きくします。小さい数字の見え方は実機確認が必要です。カード横の説明は通常サイズのまま、カスタム色は「カスタム」と表示し、元の種類とRGBはホバーで読めます。
3. 「お気に入り」の右にある「管理」から登録ライト一覧を開きます。登録0件でも管理は表示されます。旧「登録ライト一覧」の全幅ボタンはありません。5件以上登録→検索→「使う」を確認します。呼出しは種類・色だけ、配置済みの灯のOFF・強さ・位置などは保持します。空き枠なら従来どおり配置してONになります。
4. メインはお気に入り最大4件です。新規登録時は空きがあれば自動でお気に入りに入ります。4件ある状態で別の灯をお気に入りにすると、入れ替える相手を選びます。既存を勝手に外しません。お気に入り解除は登録の削除ではありません。微調整は図・ライト選択欄全体の下、カメラアイコンより下の独立した行に表示します。4件表示時にも重ならないか確認してください。
5. 一覧の「削除」は確認後に登録ファイルをArchivedへ移します。使用中の照明・保存済みプリセットの色は変わりません。登録ライトは128件までです。プリセットを登録してからライトの管理を開き、プリセット登録通知が混ざらないか確認します。ライト管理を開き直すと、その窓の前回の通知は消えます。

4. 上の①を選び、②がある丸を右クリックします。一度メニュー外をクリックして閉じ、ライトも選択も変わらないか確認します。
5. 再度右クリック→「Light 1 : ここへ重ねて移動」。①／②が同じ丸に表示されるか確認します。距離・高さなどの数値はそれぞれ保持します。
6. 重なった丸を左クリックし、①→②→①と編集対象だけ切り替わるか確認します。移動と違い、選択だけでは履歴を増やしません。
7. 「戻る」で重ね配置を取り消し、丸でライトを選び直しても「進む」が残るか確認します。別の値や配置を編集すれば、従来どおり未来の履歴は置き換わります。
8. 未配置の③を選び、空いた丸をクリックすると予定位置だけ変わり、種類を選ぶまで点灯しないか確認します。配置済みの丸へ予定位置を指定する場合も、右クリックメニューを使えます。

上の番号を押してからでも、丸を押して選んでからでも操作ルールは同じです。重なった丸を別の場所から選ぶと最小の番号を選び、その後は番号順に循環します。既に同じ方向なら右クリックの移動項目は無効です。プリセットのカード内の図はこれまでどおり見取り図で、カード選択として扱います。

## 従来の2灯ポートレート確認

1. SAM・Custom Lightなど、他の撮影ライトを消します。このツールが他MODの光を消すことはありません。
2. 三人称かフリーカメラでプレイヤーを映し、「ライトセットを選ぶ」から「白色ポートレート」を選びます。
3. 「実ライト試験を開始」を押します。上部が `2/3灯（影付き1灯）` になるか確認します。
4. Light 1はスポットの主光源、Light 2は弱い影なし補助光です。番号横の点灯マークでLight 2だけOFF/ONし、暗い部分への補助を比べてください。
5. 次に「暖色ポートレート」を選び、暖色が実際に反映されるか確認します。

白飛びする場合は各灯の強さを下げてください。色の値は試作用に調整した固定RGBで、白と暖色が同じ強さの数値でも同じ明るさに見えるとは限りません。自動の露出補正や強さの増幅はしません。

## Light 3と独立操作

- 「リムライト」は3灯です。Light 1・2が後方のスポット、Light 3が正面の影なし補助光です。光の出方は髪や衣装により異なり、完成済みの撮影レシピではありません。
- 1灯ずつOFF/ONして、その灯だけが変わるか確認します。Light 1をOFFにしてもLight 2・3は使えます。Light 3単独でも点灯できます。
- Light 3だけ「白→暖色→ろうそく→青」と変更し、他の2灯の色・強さ・配置が変わらないか確認します。
- 同じ位置へ複数灯を置いても、消灯・削除は番号単位です。重ねると明るくなるので強さを調整してください。
- 影なし／全方向の影／スポットの影、距離・高さ・範囲は各灯で独立しています。消灯中の編集で勝手に点灯しません。
- 3灯から「白色ポートレート」へ変更し、Light 3の光が残らないか確認します。「戻る」で3灯に、「進む」で2灯に戻ることも確認してください。
- 構成採用→変更→採用した構成へ戻すでも、3灯＋フェイスすべての設定を復元します。

## 撤去・ロードの確認

1. 3灯＋フェイスを点灯して「実ライト試験を停止」。全灯が消えることを確認します。単なるメニュー閉鎖では撮影ライトを維持します。
2. 再開後、Light 1～3をそれぞれ消灯・削除し、最後の1灯も残らないか確認します。全灯消灯中も編集できます。
3. テスト用セーブをロード、タイトルへ戻る、屋内外などセルを移動する操作では全灯を停止し、自動再開しない設計です。新しい撮影場所で明示的に再開してください。
4. 余裕があれば点灯中に別のテスト枠へ保存し、ゲーム終了→この試作だけ無効にして再ロードし、ライトがセーブに残らないか確認します。主セーブは上書きしないでください。

CTDがあれば繰り返さず、操作内容・クラッシュログ・`Documents/My Games/Skyrim Special Edition/SKSE/ScreenshotLightingAssistant.log` を残してください。ログは番号別の登録・色変更・撤去を記録します。ログ内のLight 4は独立フェイスです（上の3枠には追加されません）。上部の灯数は登録処理の結果で、画面上の影の品質を保証する表示ではありません。

## 今回の範囲

- スポットは共通の胸の基準点へ自動照準、90°固定です。近いと全身が照射角から外れることがあります。「光の範囲」は角度ではありません。
- 胸を取得できなければ頭、その次に足元＋1.2mが代替基準点です。カメラ基準の再取得は3灯共通です。
- ろうそくは暖かい色の固定光です。炎のオブジェクト・揺らぎはありません。
- 影方式の初期値と組み込みセットの影付きライトをスポットへ変更しました。セットを選ぶとそのセットの方式・補正値へ置き換わります。
- 複数の影付きライトの見え方・負荷・同時描画は実環境での確認が必要です。まず影付き1灯＋影なし補助光から試してください。
- プレイヤーのみが対象です。通常3灯は自由な色指定と単体／セット保存に対応しました。フェイスの色は白固定、NPC選択は未対応です。
- 作業中の設定・履歴・しおりはゲーム起動中のみ保持します。停止やロードで設定を消しませんが、ゲーム終了で失われます。明示的に登録したライト／セットだけはファイルに残ります。

MSVCビルドと19,303項目の自動テストを確認しました。既存のフェイス・位置・履歴・停止／ロードのテストに、色の分離、RGB不正値、正確なシリアライズ、日本語名、保存と再読み込み、同名拒否、破損ファイル、書き込み失敗、退避・復元を追加しています。今回0.1.17のパレット／登録画面、実ゲーム再起動での読み戻しは実機確認待ちです。モデル・ファイルテストはImGuiのマウス／IME操作やゲームの描画・撤去完了を実証するものではありません。
