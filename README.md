# Screenshot Lighting Assistant 0.2.0

Skyrimのスクリーンショット撮影向けに、対象ActorとCameraを基準とした直感的なライト配置を提供するSKSEプラグインです。

現在の正式版は **0.2.0** です。上部の人型アイコンから、プレイヤー専用・影なしの常用フェイスライト、キーボードの短押しとゲームパッドの0.6秒長押しホットキー、ロード／場所移動後の安全な自動復元を利用できます。通常の撮影ライトは従来どおり自動再開しません。

## 0.2.0 — 常用フェイスライト

- 円形UIを変更せず、上部の小さな人型アイコンから専用窓を開きます。機能とプレイヤーライトがONのときアイコンが橙色です。
- 専用窓の先頭に機能マスターを追加しました。OFF中は常用ライトを消し、登録済みキーボード／ゲームパッド入力を無視します。ライトON状態・調整値・登録キーは保持し、再び機能をONにすると復帰します。
- 常用ライトの配置は顔の向き基準へ統一しました。強さ・範囲・上下は撮影用フェイスライトとは別に保存します。
- SKSE Menu Framework専用の入力経路を使い、「変更」後はメニューを閉じずにホットキーを登録できます。Escは現在の登録を変えずにキャンセルします。
- キーボードとは別にゲームパッドのボタンを登録できます。通常プレイ中に約0.6秒長押しすると1回だけ切り替わり、離すまで再発火しません。短押しでは反応しません。
- プレイヤー撮影で撮影用フェイスライトがONなら一時的にそちらを使い、二重照明を避けます。NPC撮影中はNPC用とプレイヤー常用を併用できます。
- 照明、保存、ロード／場所移動後の復元、キーボード／ゲームパッド操作、機能マスター、顔向き固定、状態表示を含む全確認項目がゲーム内で合格しました。beta4と同じ機能コードを0.2.0正式版へ昇格しています。

- 配置方向・種類・色・影の方式・点灯状態は保持し、1回の履歴として「戻る／進む」に対応します。既定値または未配置では無効です。

## 0.1.26 — 顔向き初期値・リムライトサンプル・登録表示の整理（旧版の記録）

- 新しく開始した構成のフェイスライト方式は「顔の向き基準」が初期値です。「カメラ基準」への切替は引き続き利用できます。旧SCENE 1プリセットは互換性のため従来どおりカメラ基準として読み込み、勝手に書き換えません。

- サンプルは内蔵カードであり、「登録したプリセット」には作成されません。ユーザー登録とサンプルを重複させずに使えます。
- プリセット画面の「カードを選んで適用」は、管理・選択後も開くのチェック列とは分けて次の行へ表示します。
- ライト／プリセット登録を開き直したときと、名前欄を編集したときに、前回の同名・不正名などの登録エラーを消します。読み込み時の保存先警告は別に保持します。
- DLLビルドと44,634件の自動チェックを通過。実際の照射、カードの日本語／英語表記、登録ダイアログの見え方はゲーム内確認が必要です。

## 0.1.21 — 名前変更・日英切り替え・NPC撮影

今回の変更は以下の6点です。以降の旧版の説明と異なる場合は、この節を優先します。

- 登録ライトは「お気に入り → 管理」、自作プリセットは「P → 管理」から「名前変更」。ファイル名・お気に入り・並び順・照明値は維持し、変更前の内容をArchivedへバックアップします。同名への変更は拒否します。過去の履歴に記録した名前は当時の表記のままです。
- 上部のEN / JPで日本語と英語を切り替えます。ボタン・説明・警告・履歴の操作名を翻訳し、ユーザー登録名・NPC名は翻訳しません。言語設定だけ別ファイルへ保存します。
- 「影の補正」から(?)を削除。説明はホバーで表示します。影の処理・標準値は変えません。
- メインの選択順をスタジオ白 → スタジオ暖色 → スタジオ青 → ろうそくに変更。保存上の種類番号は従来どおりです。
- 「対象を選ぶ」でプレイヤー周囲30mの読み込み済み人型NPCを距離順に最大64人表示します。一覧を開く／更新を押すときだけ検索し、コンソール選択・クロスヘアも補助として使えます。対象を選ぶと消灯し、設定は保持します。「撮影ライトを開始」で選んだ対象を胸・頭の基準に使います。
- プリセット図は0.1.19の140px図を基準に、小丸・中央・番号・線・カメラを同じ倍率で拡大。0.1.20の左図／右情報の配置は維持します。

NPCの操作・スケジュール・ポーズ・AIは変更しません。撮影対象は同時に1人で、対象をプリセットやゲームセーブへ保存しません。ロード／メインメニューでは対象をプレイヤーへ戻し、再点灯は手動です。対象3Dの消失やセル移動では停止し、別のNPCへ自動では切り替えません。通常3灯の基準は開始／正面更新時のカメラ、フェイスライトは対象の頭と現在のカメラです。

0.1.28以降、言語設定は `Data/SKSE/Plugins/ScreenshotLightingAssistant/ui-language.sla`、登録は同じ場所の `Presets/` に置きます。MO2では通常Overwriteへ振り分けられます。0.1.17以降の登録と0.1.19以降の一覧設定は従来のSKSEログフォルダーから初回にコピーします。壊れた／未知形式の言語ファイルは上書きせず、切替はその起動中だけ反映します。

MSVCでDLL・テストをビルドし、33,492件の自動チェックを通過しました。NPCへの照射・候補選択・英語レイアウトはゲーム内未確認です。手順はREADME_TEST.md、英語ガイドはREADME_EN.mdを参照してください。MO2へは `ScreenshotLightingAssistant-0.1.21-MO2-test.zip` のみを導入し、ソースZIPは別途保管します。

## 0.1.18の操作と保存（上記の変更が優先）

- 配置図とプリセット図は設定RGBの色を表示。黒／白の番号で判読性を確保し、重なりは番号ごとの色付き丸で区別します。OFFは暗色＋斜線、編集位置は金枠です。登録名の参照や照明計算の変更はありません。
- 「登録ライト一覧」で検索・適用・お気に入り・削除を扱います。保存は従来どおり128件まで、メインの表示だけお気に入り最大3件。4件目は入替先を指定し、解除しても登録自体は残します。
- 「プリセットを選ぶ」とPは共通。カードをコンパクト化し、幅に応じ1～3列。「管理」中は照明を適用せず、自作の前後並び替え・削除、サンプルの非表示／再表示ができます。
- 「栞を登録」「栞へ戻す」をカメラ基準ボタンの横と下部に配置。起動中の1件だけの一時記憶で、カメラ位置・正面基準・全体ON/OFFは含みません。ゲーム終了後も保持するプリセットとは別です。
- 整理情報は `Presets/library-view.sla` に保存します。既存の `.slalight` / `.slaset` の形式・内容は維持。削除は `Archived/` への退避。整理ファイルの破損時は上書きせず警告し、ライト／プリセットは使用可能です。
- 色見本の上下位置、色／登録と履歴グループの余白を調整。「ライトセット」の操作名を「プリセット」に統一しました。

以下は前版までの機能説明です。旧名称「ライトセット」「構成の採用」は、現在は「プリセット」「栞の登録」です。登録の整理操作は上記を優先してください。

- Camera基準の8方向セレクター（方向名を置かず、配置済みライト番号を表示）
- 金色の枠で編集位置を表示、点灯・消灯を番号の明るさと斜線で区別
- 「1. 位置」の横にある番号ボタンでLight 1～3を選択
- 各番号の隣にある図形の点灯マークで、編集対象を変えずにON/OFF
- ライトごとに独立した種類、強さ、範囲、影、相対距離・高さ
- ライト選択の下で、選択中のライトだけを削除
- 戻る・進む・最大50件の履歴ドロップダウン
- 「現在の構成を採用」と「採用した構成へ戻す」によるしおり
- 図の下の「微調整」で開く、移動・サイズ変更可能な非モーダル窓
- メインの強さ・範囲の下に相対距離・高さ、別窓に位置パッドと追加量スライダー、微調整だけを戻すボタン

### 保存先・整理

0.1.28以降の保存先は仮想Data内の `SKSE/Plugins/ScreenshotLightingAssistant/Presets/` です。MO2では通常 `Overwrite/SKSE/Plugins/ScreenshotLightingAssistant/Presets/` に現れます。実際の場所は画面下の「登録の保存先 (?)」にマウスを載せて確認できます。物理Dataへ書き込めない非MO2環境では従来のSKSEログフォルダーへ安全にフォールバックします。

単体は `.slalight`、セットは `.slaset`。新規登録は別ファイルへ保存し、同名は上書きせずエラーにします。日本語名はUTF-8で120バイト以内、空欄は自動名です。各128件まで。再起動時に読み戻しますが、自動では適用・点灯しません。ゲームのセーブデータとは独立しています。MO2ではOverwrite内のこのフォルダーを独立したMODへ移すか、バックアップしてください。

登録した項目を右クリック→「登録から外す」で `Archived/` へ退避します。現在の照明やセットの設定値は変えません。元へ戻す場合はゲーム終了後、退避ファイルをPresets直下へ戻して再起動します。壊れた・未対応のファイルは読み飛ばして通知し、削除や書き換えはしません。古い版はこれらの登録を読み込みませんが、0.1.17に戻せば再利用できます。

## 基本の実ライト試験

Skyrimを終了し、旧版と入れ替えてテスト用セーブで確認します。SAMなど他の撮影ライトを消し、三人称またはフリーカメラでプレイヤーを映してください。

1. 「ライトセットを選ぶ」→「白色ポートレート」→「撮影ライトを開始」。
2. スポット主光源と影なし補助光の2灯が点灯します。Light 2の点灯マークで補助光だけOFF/ONして比べます。
3. 「暖色ポートレート」で色を確認し、「リムライト」でLight 3を含む3灯を確認します。
4. 個別の色・影・強さ・範囲・距離・高さを変更し、他の灯に影響しないか確認します。
5. 3灯→2灯へのセット変更、戻る・進む、最後に停止して残光がないか確認します。

詳しい確認手順は `README_TEST.md` を参照してください。0.1.17はMSVCビルドと19,303項目の自動テストを確認しました。色の分離・履歴、保存値の往復、日本語名、再読み込み、同名拒否、破損ファイル、書き込み失敗、登録の退避と復元を検証しています。0.1.16のフェイス動作は利用者確認済みです。今回のパレット入力・日本語入力・登録一覧の表示とゲーム再起動での読み戻しは実機確認待ちです。

スポットは胸の基準点へ自動照準し、90°固定です。近すぎる配置では全身が収まらない場合があります。「光の範囲」は到達範囲で、照射角ではありません。影なしは全方向に照らします。補正値や範囲を自動変更する処理、明るさを自動で増幅する処理はありません。

通常3灯の基準点は胸→頭→足元＋1.2mの順で取得し、代替時は状態を表示します。配置の水平基準は開始時のカメラ方向で固定し、「現在のカメラを正面にする」で3灯まとめて更新します。カメラのロールは反映しません。この基準更新は履歴対象外です。

メニューを閉じても光を維持します。ロード・ニューゲーム・メインメニュー・Loading Menu・セル変更・対象3D喪失では全灯を停止し、自動再開しません。通常の設置物やESP、セーブ内のライトを作らず、一時的な描画用光源だけを使います。ゲーム終了で設定・履歴は失われます。ホットDLLアンロードは対応しません。

## 操作と履歴

1. 配置済みライトはその丸をクリックして選びます。上の `1 / 2 / 3` でも選べます。
2. 空いた丸をクリックすると選択中のライトが移動します。空きスロットでは位置の指定だけで、まだ配置されません。
3. 「ライト選択」で種類を選ぶと、その番号が方向図に表示されます。
4. 「3. 基本設定」「ライトの色」と微調整窓の数値・パッドは、どれも選択中の番号だけを調整します。
5. 削除も選択中の番号だけが対象です。同じ方向に複数灯があっても他の番号には影響しません。

重ねる場合は移動元の番号を選び、移動先の丸を右クリック→「ここへ重ねて移動」を選びます。方向だけを変更し、距離・高さなどの数値は保持します。同じ丸は同じ方向を示すだけで、実空間の位置まで同じとは限りません。未配置の番号では「ここを配置予定位置にする」と表示し、種類を選ぶまで点灯しません。既に同じ方向なら移動メニューは無効です。削除したスロットの種類・数値・位置は再配置用に保持します。

番号横の点灯マークはその番号のON/OFFです。未配置の場合は無効です。OFF中も枠・位置・数値は残り、編集できます。消灯したまま種類を変えても勝手に点灯しません。削除した枠へ新しく配置した場合はONで開始します。ON/OFFは履歴・しおりにも含まれます。

## ライトセット

上部「P」または「ライトセットを選ぶ」で移動・サイズ変更可能な選択ウィンドウを開きます。背景の編集をブロックするモーダル形式です。

- サンプル8種：白色ポートレート、暖色ポートレート、リムライト、青色リムライト、暖色リムライト、キャンドル、キャンドル空間照明、片側ライティング。
- カードは上に名前、左に配置図、右に番号付きライト名を表示します。未配置の番号は省き、消灯は暗色と番号の斜線で表示します。図は保存値から描く見取り図であり、ゲーム内の完成画像ではありません。
- 灯数・ON数・配置説明の常時表示を省いてカードを低くしています。配置説明はカードのツールチップ、操作案内は一覧上部の「使い方」のツールチップにあります。
- 右のライト名は情報表示です。どの部分をクリックしてもカード全体の構成を適用します。
- 通常は2列で図とラベルを横並びにし、フォントサイズに対して幅が不足する場合は1列へ、さらに狭い場合はラベルを図の下へ回します。
- カード選択で3灯すべてを置き換え、選択ウィンドウを閉じます。2灯のセットなら残り1枠は未配置になります。独立フェイスの設定は、フェイスを含めて登録した自作セット以外では保持します。
- 適用は履歴1件として記録され、「戻る」で適用直前の構成へ戻せます。同じ構成を再適用しただけでは履歴を増やしません。
- ×で閉じるだけでは構成やしおりは変わりません。カードを眺めるだけでも変わりません。
- 「片側ライティング」はLight 2をOFFで保持する比較用サンプルです。
- 適用はしおりの採用とは別です。サンプルの照明値は3灯の実機結果を見ながら調整予定です。
- 自作ライトセットは「ライトセット登録」で保存します。詳細は上の0.1.17の説明を参照してください。

スライダーはドラッグ終了または数値入力の確定時に1件の履歴として記録します。変更のない操作や番号ボタン／丸での選択だけでは記録しません。履歴は3灯＋独立フェイス全体のスナップショットで、復帰時はその時点の編集対象番号も復元します。

履歴から過去へ戻った後、新しく変更すると、その先の履歴が新しい操作に置き換わります。しおりは履歴とは別に保持され、履歴の上限を超えても残ります。「採用した構成へ戻す」自体も取り消せます。

**作業中の設定・履歴・しおりはゲーム起動中だけ保持します。残したい構成は「ライトセット登録」でファイルへ保存してください。登録済みのライトとセットはゲーム終了後も残ります。セーブデータには記録しません。**

## First in-game check

実光源の初回試験は上の「基本の実ライト試験」の順で行い、続けて以下のUI回帰確認を行ってください。

1. SKSE Menu Frameworkを開く。
2. `Screenshot Lighting Assistant > Lighting` を開く。
3. 上の番号ボタンでLight 2を選び、空いた丸・種類の順に選択して配置する。
4. Light 1と2で強さ・範囲・距離・高さ・影を変え、切り替えても各設定が保持されることを確認する。
5. 「Light 2 を削除」→「戻る」→「進む」で番号が消える・戻る・消えることを確認する。
6. スライダーを長くドラッグしても履歴が1件だけ増えることを確認する。
7. 構成を採用→変更→採用した構成へ戻す→履歴の戻る、を試す。
8. 普段の解像度・フォントサイズでボタン文字の中央揃えと横切れ・重なりを確認する。
9. 番号横の点灯マークでON/OFFし、選択番号が変わらず数値も残ることを確認する。
10. ライトセットを開く→×で閉じる→再度開く→カード選択で閉じる、を試す。
11. セット選択後に「戻る」で元の3灯に復帰することを確認する。

ボタンは実際のフォントと余白から高さ・幅を求めます。横幅が不足する場合、ライト選択は方向図の下に回り込みます。
